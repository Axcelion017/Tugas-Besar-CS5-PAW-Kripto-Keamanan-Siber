# Inventaris Aset Keamanan (*Asset Inventory*) — Resilio-Health

Inventaris aset sistem informasi rumah sakit Resilio-Health mencakup data klinis sensitif, berkas citra radiologi terenkripsi, kunci kriptografi, kredensial otorisasi 4-peran, dokumen identitas e-KYC/KYD ber-watermark, dan infrastruktur ketahanan *Offline-First*.

---

## Tabel Inventaris Aset Sistem (AST-01 s.d. AST-12)

| ID Aset | Nama Aset | Kategori | Deskripsi | Klasifikasi Kerahasiaan | Dampak Kehilangan / Kebocoran | Kontrol Perlindungan Sistem |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **AST-01** | Rekam Medis Elektronik (EHR - SOAP Payload) | Data Klinis | Data keluhan (S), tanda vital fisik (O), diagnosa ICD-10 (A), dan resep obat (P) | Sangat Rahasia (Confidential / PII Medis) | **Kritis**: Pelanggaran berat privasi pasien (UU PDP No. 27/2022), malpraktik medis, sanksi pidana | Enkripsi AES-256-GCM sisi klien, verifikasi digest HMAC-SHA256, Zero-Knowledge Admin |
| **AST-02** | Kunci Enkripsi Pasien (DEK 256-bit) | Kriptografi | Kunci heksadesimal 256-bit unik per pasien untuk proses enkripsi & dekripsi data medis | Sangat Rahasia (Strict Secret) | **Kritis**: Seluruh riwayat medis pasien terkait dapat didekripsi dan dibaca oleh pihak luar | Isolasi memori runtime sesi, pembersihan otomatis saat logout, Zero-Knowledge Storage |
| **AST-03** | Token Sesi & Status 4 Peran Pengguna | Kredensial | Data identitas sesi aktif pengguna (Pasien, Staf Nakes Triase/Admisi, Dokter DPJP, Admin Regulator) | Rahasia (Secret) | **Tinggi**: Pembajakan akun (*Session Hijacking*), eskalasi hak akses (*Privilege Escalation*) | Validasi sesi runtime, Route Guard terproteksi, isolasi rute `(dashboard)` 4 domain |
| **AST-04** | Log Audit Keamanan & Jejak SIEM | Data Audit | Jejak pencatatan akses DPJP, penolakan BOLA/IDOR, kegagalan HMAC, aktivasi Break-Glass, dan kill-switch | Internal Terbatas | **Tinggi**: Penyangkalan tindakan medis (*Repudiation*), kegagalan audit forensik siber | Pencatatan otomatis timestamp, aktor, IP terminal, dan severity level; append-only storage |
| **AST-05** | Antrean Sinkronisasi Lokal (IndexedDB Queue) | Penyimpanan Lokal | Berkas rekam medis dan citra biner yang mengantre di browser saat internet faskes putus | Sangat Rahasia [TERENKRIPSI] | **Tinggi**: Kehilangan data saat browser crash, modifikasi data offline secara ilegal | Disimpan dalam bentuk ciphertext AES-GCM + digest HMAC; verifikasi integritas wajib sebelum sync |
| **AST-06** | Berkas e-KYC KTP & Swafoto Ber-Watermark | Data Identitas | Foto fisik KTP asli dan swafoto wajah (*liveness check*) dengan auto-watermark transparan digital | Rahasia (Restricted PII) | **Tinggi**: Pencurian identitas nasional untuk pinjol ilegal, pemalsuan akun pasien | Client-Side Auto-Watermarking Canvas sebelum unggah; akses visual terkunci untuk Admin Kemenkes |
| **AST-07** | Tiket Persetujuan Akses Medis (Consent Grants) | Otorisasi | Relasi izin aktif antara pasien dan dokter/faskes (`access_grants`) beserta masa berlaku | Rahasia | **Tinggi**: Pelanggaran hak kedaulatan data medis pasien (UU PDP Pasal 20) | Pertahanan BOLA/IDOR Gatekeeper; mekanisme 1-Click Revoke seketika |
| **AST-08** | Status Jaringan Faskes & Ransomware Kill-Switch | Konfigurasi | Pengaturan status operasional faskes (`ACTIVE` vs `QUARANTINED`) | Internal Kritis | **Kritis**: Masuknya transmisi malware/ransomware dari faskes terinfeksi ke jaringan RME nasional | Otoritas eksklusif Admin Regulator; isolasi faskes instan dari API gateway nasional |
| **AST-09** | Citra Medis Biner (Rontgen, USG, Lab, EKG Blob) | Data Diagnostik | File citra radiologi biner berukuran besar (X-Ray Thorax, USG Abdomen, Scan Lab, EKG) | Sangat Rahasia (Confidential Blob) | **Kritis**: Eksfiltrasi citra diagnostik sensitif, manipulasi bayangan tumor/fraktur tulang | Konversi ke binary Buffer, enkripsi AES-256-GCM Blob, digest HMAC mandiri, simpan di IndexedDB |
| **AST-10** | Tiket Sesi Pertemuan DPJP (Active Encounter Ticket) | Otorisasi Klinis | Tiket sesi periksa aktif yang diterbitkan staf admisi mengunci dokter spesialis sebagai DPJP sah | Rahasia Operasional | **Tinggi**: Pembukaan rekam medis tanpa penugasan klinis, dokter poli lain mengintip data | Penguncian DPJP berbasis 6-Digit PIN Pasien; masa berlaku 12 jam otomatis kedaluwarsa |
| **AST-11** | Log Audit Darurat Break-Glass IGD | Data Forensik | Rekaman pembukaan rekam medis darurat (alergi, golongan darah) untuk pasien koma/kritis di IGD | Sangat Kritis (Audit Legal) | **Kritis**: Penyalahgunaan wewenang dokter membuka data selebritas/pejabat tanpa indikasi medis | Wajib menyertakan indikasi klinis darurat; otomatis memicu High-Severity Alert ke SIEM Kemenkes |
| **AST-12** | Catatan Revisi Medis (Immutable Addendum) | Integritas Medis | Riwayat koreksi diagnosis bertingkat (Versi 1, Versi 2) tanpa menghapus rekaman riwayat awal | Legal Medikolegal | **Tinggi**: Pemalsuan rekam medis pasca kejadian, hilangnya bukti hukum malpraktik | Sifat immutable Permenkes No. 24/2022; penambahan versi baru berstempel waktu & alasan addendum |
